# Blender asset brief

Build the cage first, then one Space Marine base directly in Blender via MCP.

- Industrial shipboard cage: enclosed arena, readable entrance, physical lattice, floor plates/grates, mechanical structure and practical lights.
- First armoured marine: bulky silhouette, distinct helmet, breastplate, pauldrons, articulated limbs, backpack, axe; separated named pieces and pivot hierarchy as an animation starting point.
- Deliver editable native Blender project, reproducible build scripts, separate GLB exports and actual Blender renders.
- Original authored geometry, no extracted or purchased assets. Fan-art science-fiction design, no AAA or official-product claim.
- Verify export geometry/materials and render visually. This delivery is asset creation; replacing the existing game's animation system is a later integration step. No rigged/skinned character or final combat animation claim.
