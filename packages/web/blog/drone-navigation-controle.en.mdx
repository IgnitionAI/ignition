A drone climbs, tilts, then drifts. Reaching a target takes more than an upward push: orientation and velocity change what the motion does next.

This demo connects a discrete choice to a physical action. The agent picks a motor combination; the thrust and torques then produce a displacement. Understanding this mechanism helps you read control failures.

**You will run the experiment and understand the link between its observations, its decisions, and its outcome.**

## What the agent receives

DroneEnv exposes eight combinations: two levels of uniform thrust, forward, backward, left, right, and two rotations. Its observation contains 13 values, including the offset to the target, some velocities, the tilt, the position, and the distance. The observe() function is the exact contract: not all physical fields are transmitted.

## What the reward encourages

The reward combines a distance penalty, a progress bonus, and a rotation penalty. Capturing a target adds +50; a crash is worth −20. An episode ends at a crash or at 1,000 transitions. Position and motion come from a TypeScript integration; the scene's Rapier context does not replace this dynamics.

The full contract lives in [drone-env.ts](https://github.com/IgnitionAI/ignition/blob/main/packages/demo-drone-navigation/src/drone-env.ts). Read `observe()`, `step()`, and `reward()` together: a benchmark's name is not enough to define its implementation.

## Reproduce the experiment with code

Use Node.js 20 or 22 and pnpm 10.8.0. From the repository:

```bash
git clone https://github.com/IgnitionAI/ignition.git
cd ignition
corepack enable
pnpm install --frozen-lockfile
pnpm --filter demo-drone-navigation dev --host 127.0.0.1 --port 5173
```

Open [localhost:5173](http://localhost:5173). On a VPS, use an SSH tunnel to that port to access it from your computer.

The example is loaded directly from [blog-experiment.ts](https://github.com/IgnitionAI/ignition/blob/main/packages/demo-drone-navigation/src/examples/blog-experiment.ts): the article's code and the repository's code stay in sync.

While Vite is running, you can import this module in the browser console:

```js
const { createExperiment } = await import('/examples/blog-experiment.ts');
const session = createExperiment();
// Après quelques tentatives :
session.infer();
session.stop();
```

The module creates an independent session. It does not wire it into the already-open scene: use the demo's buttons for the visual walkthrough. infer() applies the current policy without training; resume() keeps the agent and stop() cancels upcoming ticks. A transition already in progress can still finish.
