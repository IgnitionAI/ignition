A starting cell. A target. Four possible directions. GridWorld lets you follow an agent's decision without having to interpret a complex physical simulation.

A reward turns a walk on the grid into an optimization problem: arriving counts, but detours have a cost too. It is a readable playground for understanding how experiences change action values.

**You will run the experiment and understand the link between its observations, its decisions, and its outcome.**

## What the agent receives

The default grid measures 7 × 7. The agent starts in the top-left and the target stays in the bottom-right. The observation contains the normalized coordinates of the agent and the target. The actions are up, right, down, and left; an action against a border keeps the position.

## What the reward encourages

Each non-winning move earns −0.1, and reaching the target earns +10. The episode stops at the target or after 100 transitions. Without obstacles, 12 moves suffice from the start: this is a geometric reference point, not a guaranteed training score.

The full contract lives in [gridworld-env.ts](https://github.com/IgnitionAI/ignition/blob/main/packages/demo-gridworld/src/gridworld-env.ts). Read `observe()`, `step()`, and `reward()` together: a benchmark's name is not enough to define its implementation.

## How the table changes a decision

Q-Table maps each encoded state to a value per action. A transition provides a target: the immediate reward, plus the best estimated value in the next state if the transition is not terminal. The update gradually brings the chosen action's value closer to that target. At inference, the agent keeps the maximum-value action; during training, exploration also lets it try other actions.

This estimate explains why a rewarded arrival can eventually influence decisions made several cells earlier. It depends, however, on the experiences collected and the discretization used.

## Reproduce the experiment with code

Use Node.js 20 or 22 and pnpm 10.8.0. From the repository:

```bash
git clone https://github.com/IgnitionAI/ignition.git
cd ignition
corepack enable
pnpm install --frozen-lockfile
pnpm --filter demo-gridworld dev --host 127.0.0.1 --port 5173
```

Open [localhost:5173](http://localhost:5173). On a VPS, use an SSH tunnel to that port to access it from your computer.

The example is loaded directly from [blog-experiment.ts](https://github.com/IgnitionAI/ignition/blob/main/packages/demo-gridworld/src/examples/blog-experiment.ts): the article's code and the repository's code stay in sync.

While Vite is running, you can import this module in the browser console:

```js
const { createExperiment } = await import('/examples/blog-experiment.ts');
const session = createExperiment();
// Après quelques tentatives :
session.infer();
session.stop();
```

The module creates an independent session. It does not wire it into the already-open scene: use the demo's buttons for the visual walkthrough. infer() applies the current policy without training; resume() keeps the agent and stop() cancels upcoming ticks. A transition already in progress can still finish.
